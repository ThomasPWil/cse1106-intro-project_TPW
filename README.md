# cse1106-intro-project_TPW
Repo for my intro to computer science class

# project title: Dice battle

## description: dice game where a player and computer role dice between 1 and 6
## whoever has the highest value will win. First to 10 points wins the game
## if a player roles a zero they lose a point

## instructions: download the file and navigate to downloaded folder in terminal then use
## gcc Dice_Battle.c when in project folder then use ./a.out to run the program
## Use the 1 key when prompted to start the game then use 1
## on the keyboard to roll the dice when prompted

## What I learned: learned how to use pointers as well as difference between & and * when using pointers 
## as well as fgets for user input

## Future Improvments: will add double dice to get more rolls and add the ability to get 2 points for rolling a 6 instead of just 1.
